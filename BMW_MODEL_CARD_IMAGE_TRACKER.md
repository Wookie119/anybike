# BMW model card image verification tracker

This is a sourcing checklist, **not permission to publish images**. Before adding an image to AnyBike, confirm the exact model and generation, inspect the actual downloaded picture, check usage rights/attribution, and store a properly sized copy as a local asset. Never use a stock-sale listing or an ambiguous search thumbnail as a model reference.

Preferred presentation: 16:9 image above the model name, `object-fit: contain` on a dark background, descriptive alt text, and the existing 'Check availability from the UK market →' action. No photo should be added to the live cards until verified.
